## 💻 Run Locally

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/asher-portfolio.git
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build the project:

```bash
npm run build
```
